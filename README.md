# DSD 뷰어 — 브라우저에서 여는 공시서류 열람기

금융감독원 **DART 편집기 문서(`.dsd`)** 를 스마트폰이나 PC 브라우저에서 바로 열어 보는 뷰어입니다.
설치할 것도, 가입할 것도 없습니다.

## 👉 바로 쓰기

**https://henmoogi.github.io/dsd-viewer/**

주소를 열고 **파일 선택**을 눌러 `.dsd` 파일을 고르면 끝입니다.

> 아이폰·아이패드에서도 사파리로 그대로 쓸 수 있습니다. 사파리의 **공유 → 홈 화면에 추가**를 하면
> 앱처럼 아이콘으로 띄워 둘 수 있습니다. 안드로이드 크롬도 **메뉴 → 홈 화면에 추가**가 됩니다.

## 파일이 어디로도 전송되지 않습니다

이 뷰어는 **파일을 서버로 올리지 않습니다.** 브라우저 안에서만 열고 그립니다.

- 페이지 전체가 **HTML 파일 하나**이고, 외부 서버 통신 코드가 **한 줄도 없습니다.**
  (`fetch`·`XMLHttpRequest`·외부 스크립트·외부 CSS·추적 코드 전부 0건)
- 한 번 열어 둔 뒤에는 **비행기 모드에서도 동작**합니다.
- 소스가 이 저장소에 그대로 있으니 직접 확인하실 수 있습니다 → [`index.html`](index.html)

감사조서나 미공시 자료처럼 민감한 문서를 다룰 때 중요한 부분이라 명시해 둡니다.

## 기능

- `.dsd`(실체는 ZIP) 자동 압축해제 → DART 마크업(TABLE/TE/TU, USERMARK 등) 파싱·렌더링
- 인코딩 자동 감지
- 재무제표 **3열 자동 병합**(간략 보기), 원본/맞춤 전환
- **틀고정** — 머리글·과목 고정한 채로 표 스크롤
- 목차(국문/영문), 본문 검색
- 라이트 / 세피아 / 다크 모드, 글자 크기 조절

## 이럴 때 씁니다

- 외부에서 급히 공시 초안을 확인해야 하는데 PC가 없을 때
- `.dsd`를 메일이나 메신저로 받았는데 DART 편집기가 깔린 PC가 없을 때
- 태블릿으로 재무제표를 넘겨 보며 검토할 때

## 안드로이드 앱 버전

같은 엔진을 쓰는 안드로이드 앱도 있습니다. 파일관리자에서 `.dsd`를 탭하면 바로 열리는 게 장점입니다.
필요하시면 이슈로 문의해 주세요.

## 한계

- `.dsd`는 표준 형식이 아니라 DART 편집기 전용 형식입니다. 편집기 버전에 따라 일부 표현이
  다르게 보일 수 있습니다.
- **읽기 전용**입니다. 편집·저장 기능은 없습니다.
- 아주 큰 문서는 기기 메모리에 따라 느리거나 열리지 않을 수 있습니다.
- 금융감독원·DART의 공식 제품이 아닙니다. 개인이 만든 도구입니다.
